# Лабораторные работы по курсу «Нейронные сети, машинное обучение и искусственный интеллект»

Учебный репозиторий с лабораторными работами по дисциплине **«Нейронные сети, машинное обучение и искусственный интеллект»**.

В репозитории последовательно рассматриваются основные подходы к построению и обучению моделей машинного обучения: от подготовки и анализа данных до реализации алгоритмов регрессии, классификации и нейронных сетей. Часть алгоритмов реализуется самостоятельно с использованием базовых возможностей Python и NumPy, а также рассматриваются готовые инструменты из библиотек Scikit-Learn и PyTorch.

## Лабораторные работы

### Лабораторная работа №1 — Подготовка окружения. Jupyter Notebook и Pandas

**Цель:** подготовить окружение для выполнения лабораторных работ, познакомиться с Jupyter Notebook и освоить основные возможности Pandas для обработки и анализа данных.

**Основные задачи:**

* подготовка Python-окружения;
* работа с Jupyter Notebook и JupyterLab;
* использование Markdown и LaTeX;
* загрузка и обработка данных с помощью Pandas;
* очистка и подготовка данных;
* исследование и визуализация набора данных Titanic;
* построение графиков с использованием Matplotlib и Seaborn.

**Инструменты:** `Python`, `Jupyter Notebook`, `JupyterLab`, `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`.

---

### Лабораторная работа №2 — Линейная регрессия и градиентный спуск

**Цель:** изучить построение модели линейной регрессии и методы поиска её параметров аналитическим способом и с помощью градиентного спуска.

**Основные задачи:**

* аналитическое вычисление параметров линейной регрессии;
* использование матричных операций NumPy;
* построение линии регрессии;
* реализация Batch, Stochastic и Mini-batch Gradient Descent;
* исследование сходимости методов;
* анализ изменения функции ошибки и MSE;
* сравнение полученных моделей;
* реализация линейной регрессии с использованием Scikit-Learn.

**Инструменты:** `Python`, `Jupyter Notebook`, `Pandas`, `NumPy`, `Matplotlib`, `Scikit-Learn`.

---

### Лабораторная работа №3 — Бинарный линейный классификатор. Градиентный спуск

**Цель:** изучить принцип работы бинарного линейного классификатора и освоить поиск разделяющей линии с помощью градиентного спуска.

**Основные задачи:**

* вычисление коэффициентов разделяющей линии;
* расчёт отступов объектов;
* анализ правильности классификации;
* реализация бинарного линейного классификатора;
* реализация градиентного спуска для настройки весов;
* минимизация функции потерь;
* визуализация обучающей выборки и разделяющей линии.

**Инструменты:** `Python`, `Jupyter Notebook`, `NumPy`, `Matplotlib`.

---

### Лабораторная работа №4 — Решающие деревья

**Цель:** изучить принцип построения и применения решающих деревьев для решения задач классификации с использованием Scikit-Learn.

**Основные задачи:**

* разбор примеров построения решающих деревьев с использованием Scikit-Learn;
* построение решающего дерева для задачи моделирования приёма студентов;
* визуализация структуры решающего дерева;
* построение решающих деревьев для заданного набора данных;
* разделение данных на обучающую и тестовую выборки в соотношении 80:20;
* построение различных вариантов решающих деревьев;
* построение матрицы ошибок (`Confusion Matrix`);
* расчёт метрик качества классификации: `accuracy`, `precision`, `recall`;
* сравнение полученных моделей и выбор наиболее удачного решающего дерева.

**Инструменты:** `Python`, `Jupyter Notebook`, `Pandas`, `NumPy`, `Matplotlib`, `Scikit-Learn`.

---

### Лабораторная работа №5–6 — Обучение нейронных сетей в PyTorch

**Цель:** изучить принципы работы искусственных нейронных сетей и методы их обучения на языке Python, а также решить задачу классификации с использованием PyTorch.

**Основные задачи:**

* изучение базовых принципов работы искусственных нейронных сетей;
* построение однослойного нейронного классификатора;
* работа с тензорами PyTorch;
* использование автоматического дифференцирования и `autograd`;
* применение градиентного спуска и оптимизаторов;
* работа с `Dataset` и `DataLoader`;
* загрузка и обработка набора данных MNIST;
* построение и обучение нейронной сети для классификации изображений;
* оценка качества классификации на тестовой выборке;
* построение кривых обучения и анализа ошибки;
* построение двухслойной нейронной сети;
* исследование функции активации и функции потерь;
* построение матрицы ошибок (`confusion matrix`).

**Инструменты:** `Python`, `Jupyter Notebook`, `PyTorch`, `torchvision`, `NumPy`, `Matplotlib`.
